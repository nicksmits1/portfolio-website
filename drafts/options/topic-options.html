1. Topics as the home minima

Five topic basins replace the seven project minima. A project can belong to more than one topic, so the first question is the grouping. Here is my proposal; change any dot. A ring marks a project's second topic. Option B needs exactly one home per project, so it uses the filled dots only.

A

Topic basins, one page per topic

Each topic is one minimum, labelled with its project count. Click a label, or converge on one, to open /topics/<id>. That page uses the same arrival as a project page: the topic's projects become the minima, neighbouring topics are previous and next, and the topic's project rows sit below. Home becomes a two-step descent: topic, then project.

Gains

  • Each level of the landscape does one job: home shows the fields, a topic shows its work.
  • Topics take any number of projects; a new project joins a topic page, and home doesn't change.
  • A project can appear on two topic pages.

Costs

  • One more click from home to a project.
  • Five new pages, each needing a lead line of its own so it doesn't repeat home.

Build

content/topics/<id>.md (name, line, order), a topics field per project, src/pages/topics/[id].astro reusing Strip and the rows. Project pages could keep site-wide previous and next, or switch to neighbours within the topic.

B

Nested basins: topics broad, projects inside

Each topic is a wide, shallow basin, and its projects are small, deeper dimples inside it. The landscape shows both scales at once, so a descent falls into a field and then settles on a project. Topic labels open topic pages as in A; project labels still go straight to the project.

Research and projects

Gains

  • Smallest change: no new pages, nothing new to keep from going stale.
  • Projects can sit under several topics.

Costs

  • A topic has no address of its own to put on a poster or in an email.
  • The descent ends in a filter rather than a destination, which is a weaker payoff for the click.

Build

A topics field per project, a topics data file for names and map places, the chip row, and a hash (/#rl) so a filtered list can be linked.
