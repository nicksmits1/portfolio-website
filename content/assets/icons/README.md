Link icons for the profile and contact rows.

- `github.svg`, `orcid.svg`: Simple Icons 13.21.0, CC0.
- `linkedin.svg`: Simple Icons 10.4.0 (later versions dropped it at LinkedIn's request), CC0. The mark is LinkedIn's trademark; use it only to link to the profile.
- `mail.svg`, `file-down.svg`: Lucide 0.460.0, ISC.

Brand marks are filled paths (`fill="currentColor"` when inlined); Lucide icons are 2px strokes.
